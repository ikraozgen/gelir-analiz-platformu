# 📊 Gelir & Pasif Gelir Analiz Platformu

Türkiye genelinde çalışanların net gelir ve pasif gelir trendlerini anonim olarak toplayan ve gerçek zamanlı analiz eden uçtan uca veri platformu.

## 🚀 Teknolojik Mimari
* **Web Arayüzü & Görselleştirme:** Streamlit & Plotly (Python)
* **Veritabanı:** PostgreSQL (Supabase Cloud)
* **Veri Güvenliği & İzinler:** Row Level Security (RLS) - Anonim açık veri toplama
* **Veri Analitiği:** Pandas ile filtreleme, gruplama ve istatistiksel özetleme

## 💻 Çalıştırma
```bash
cd "C:\Users\PC\.gemini\antigravity\scratch\gelir_analiz_platformu"
streamlit run app.py
```
